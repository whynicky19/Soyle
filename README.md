# Söyle

Полноценный учебный MVP веб-платформы для игровых речевых занятий и поддерживаемой коммуникации. Söyle объединяет ребёнка, родителя и специалиста в одной персональной программе. Публичный лендинг доступен на `/`, вход и кабинеты — на `/app`.

> Söyle не ставит диагноз и не заменяет врача или логопеда. Цели и упражнения для ребёнка необходимо согласовывать со специалистом.

## Возможности

- Регистрация родителей и вход по JWT.
- Роли: администратор, родитель, специалист и ученик.
- Профили детей и изоляция данных родителей.
- 21 задание трёх уровней сложности.
- MediaPipe Face Landmarker для локальной оценки артикуляции.
- Синтез русской речи для слов и AAC-фраз.
- Запись результатов занятий и расчёт реального прогресса: SQLite локально, PostgreSQL в production.
- Персональный план: сначала обязательные назначения специалиста, затем слабые навыки и разнообразие упражнений.
- Индивидуальные цели со сроком, критерием, сложностью и статусом.
- Занятия на 3, 5 или 10 минут, визуальное расписание, пауза и сохранение незавершённого занятия.
- Домашние задания с пятью вариантами результата и отображением специалисту.
- Учёт самостоятельности, подсказок, времени ответа и коммуникационных инициатив.
- Админ-панель: статистика, роли, блокировка аккаунтов, добавление и архивация заданий.
- Учёт ресурсов автоматических функций: запросы, токены, модель, функция и расчётная стоимость.
- Кабинет специалиста с целями, назначениями, домашней практикой и объяснимым умным подбором.
- Темы: шалфей, эвкалипт, олива и контрастная. Выбор сохраняется в аккаунте.
- Ограничение попыток входа, журнал критических действий, согласия, экспорт и удаление данных ребёнка через API.

## Стек

- Frontend: Next.js 16, React 19, TypeScript, MediaPipe, Web Speech API.
- Backend: FastAPI, PostgreSQL/SQLite, Pydantic, PyJWT, Argon2.

## Запуск backend

### Быстрый запуск

Из корневой папки проекта запустите оба сервера одной командой:

```bash
./start.sh
```

Остановка: `Ctrl+C`. Frontend откроется на http://localhost:3000, API — на http://127.0.0.1:8010.

### Раздельный запуск

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export SOYLE_SECRET_KEY="replace-with-a-long-random-secret"
uvicorn app.main:app --reload --port 8010
```

Swagger: http://127.0.0.1:8010/docs

## Запуск frontend

Во втором терминале:

```bash
cd frontend
npm install
cp .env.local.example .env.local
npm run dev
```

Сайт: http://localhost:3000

## Автоматические тесты

```bash
cd backend
source .venv/bin/activate
pip install -r requirements-dev.txt
pytest -q
```

Тесты проверяют авторизацию и роли, изоляцию данных детей, ограничение попыток входа, приоритет обязательного упражнения, цели, домашнюю практику, паузу занятия и расширенные показатели прогресса.

## Локальные демо-аккаунты

Демо-данные создаются только при локальной работе с SQLite. Для явного включения задайте `SOYLE_SEED_DEMO_DATA=true`. В production эта настройка должна оставаться `false`; администратор создаётся один раз из `SOYLE_ADMIN_USERNAME` и `SOYLE_ADMIN_PASSWORD`.

## Deployment на Vercel

Проект разворачивается как два Vercel-проекта из одного репозитория:

- `frontend` — Next.js, переменная `NEXT_PUBLIC_API_URL` указывает на адрес API;
- `backend` — FastAPI, подключённый к PostgreSQL через `DATABASE_URL`.

Обязательные переменные backend перечислены в `backend/.env.example`. В production задайте `SOYLE_ENV=production` и уникальный `SOYLE_SECRET_KEY` длиной не менее 32 байт. Локальные `.env*`, SQLite-базы и служебная папка `.vercel` исключены из Git.

При запуске `init_db()` автоматически применяется совместимая миграция схемы версии 2: добавляются цели, домашняя практика, согласия, журнал действий, ограничение входа и новые показатели занятий. Существующие маршруты сохранены.

## Приватность

- Кадры камеры обрабатываются MediaPipe в браузере и не отправляются в API.
- Видео и звук не сохраняются.
- Backend хранит аккаунты, профили детей и результаты занятий.
- Для реального пилота нужны юридически проверенное согласие законного представителя, политика обработки данных, резервное копирование и проверка упражнений логопедом.
