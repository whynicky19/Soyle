# Söyle

Полноценный учебный MVP веб-платформы для игровых речевых занятий и поддерживаемой коммуникации. В проекте есть авторизация, роли, база данных, админ-панель, кабинет специалиста, три игровых модуля и AI-компонент компьютерного зрения.

> Söyle не ставит диагноз и не заменяет врача или логопеда. Цели и упражнения для ребёнка необходимо согласовывать со специалистом.

## Возможности

- Регистрация родителей и вход по JWT.
- Роли: администратор, родитель, специалист и ученик.
- Профили детей и изоляция данных родителей.
- 18 заданий трёх уровней сложности.
- MediaPipe Face Landmarker для локальной оценки артикуляции.
- Синтез русской речи для слов и AAC-фраз.
- Запись результатов занятий в SQLite и расчёт прогресса.
- Персональный план на основе наиболее слабого навыка.
- Админ-панель: статистика, роли, блокировка аккаунтов, добавление и архивация заданий.
- Учёт AI-ресурсов: запросы, входные и выходные токены, модель, функция и расчётная стоимость.
- Кабинет специалиста со списком детей и AI-рекомендациями.
- Темы: персиковая, океан, лаванда и контрастная. Выбор сохраняется в браузере.

## Стек

- Frontend: Next.js 16, React 19, TypeScript, MediaPipe, Web Speech API.
- Backend: FastAPI, SQLite, Pydantic, PyJWT, Argon2.

## Запуск backend

### Быстрый запуск

Из корневой папки проекта запустите оба сервера одной командой:

```bash
./start.sh
```

Остановка: `Ctrl+C`. Frontend откроется на http://localhost:3000, API — на http://127.0.0.1:8010.

### Раздельный запуск

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export SOYLE_SECRET_KEY="replace-with-a-long-random-secret"
uvicorn app.main:app --reload --port 8010
```

Swagger: http://127.0.0.1:8010/docs

## Запуск frontend

Во втором терминале:

```bash
cd frontend
npm install
cp .env.local.example .env.local
npm run dev
```

Сайт: http://localhost:3000

## Приватность

- Кадры камеры обрабатываются MediaPipe в браузере и не отправляются в API.
- Видео и звук не сохраняются.
- Backend хранит аккаунты, профили детей и результаты занятий.
- Для реального пилота нужны согласие законного представителя, политика обработки данных, резервное копирование и проверка упражнений логопедом.
