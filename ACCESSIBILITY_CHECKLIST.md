# Söyle — checklist детского интерфейса и доступности

Дата проверки: 7 октября 2026 года.

## Структура и управление

- [x] Все видимые кнопки на главном мобильном экране имеют доступное имя.
- [x] Кнопка возврата в игровых экранах имеет имя «Назад к занятиям».
- [x] Логотип является настоящей кнопкой, а не кликабельным `div`.
- [x] Основная навигация и категории AAC имеют подписи для вспомогательных технологий.
- [x] Выбранные длительность, скорость речи, категория AAC, уровень помощи и настройки передают состояние через `aria-pressed`.
- [x] Быстрые AAC-сообщения и карточки управляются клавиатурой; фокус видим.
- [x] Текст обратной связи объявляется через live-region без принудительного перемещения фокуса.

## Сенсорный и визуальный комфорт

- [x] Основные сенсорные цели на мобильном экране не меньше 44×44 CSS px; исключение — служебная кнопка Next.js, доступная только в dev-режиме.
- [x] Спокойный режим отключает декоративные анимации и конфетти.
- [x] Системная настройка `prefers-reduced-motion` также отключает движение.
- [x] Есть контрастная тема, отдельная настройка звука и независимое отключение камеры.
- [x] Карточки сенсорного задания не раскрывают ответ текстом до завершения попытки.
- [x] Критические AAC-сообщения доступны крупными кнопками за одно нажатие.

## Упрощённый режим ребёнка

- [x] В ученическом аккаунте остаются четыре понятных раздела: «Главная», «Занятия», «Сказать», «Настройки».
- [x] Кабинеты родителя, специалиста, администратора и аналитический экран прогресса отсутствуют в детской навигации.
- [x] Второстепенный блок статистики в боковой панели скрыт, а подписи карточек и элементы управления увеличены.
- [x] Отказ и перерыв доступны непосредственно внутри учебных AAC- и моторных заданий.

## Адаптивность

- [x] Главный экран вручную проверен при 390×844: нет горизонтального переполнения, карточки читаемы, баннер согласия перестраивается в одну колонку.
- [x] Основные игровые сетки перестраиваются на две или одну колонку на узких экранах.
- [x] Production build и TypeScript проходят после responsive-изменений.

## Проверки, обязательные перед внешним пилотом

- [ ] Очная проверка с детьми, использующими switch control, screen reader или альтернативный ввод.
- [ ] Проверка на реальных iOS/Android-устройствах и планшетах, включая изменение масштаба текста до 200%.
- [ ] Проверка цветов и пиктограмм с представителями целевой аудитории, а не только автоматическими инструментами.
