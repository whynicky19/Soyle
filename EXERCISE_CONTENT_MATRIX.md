# Söyle — матрица соответствия учебных заданий

Дата проверки: 7 октября 2026 года.

Матрица фиксирует только техническое соответствие названия задания доступной механике. Она не заменяет очную проверку логопедом, AAC-специалистом, лингвистом и пользователями.

## Активные задания

| Модуль | Цели | Реальная механика | Статус |
|---|---|---|---|
| Моторный | `smile`, `tube`, `open`, `teeth`, `cheeks`, `sequence` | Визуальный пример движения; локальное зеркало камеры при отдельном согласии | Активно; безопасный ручной режим добавляется в модуле 8 |
| Слуховое понимание | `animals`, `food`, `toys` | Слово озвучивается; ребёнок выбирает одну из трёх неподписанных картинок; есть повтор и ступени помощи | Активно; по 8 стимулов в теме |
| Учебная AAC | `request`, `choice`, `refusal`, `feelings`, `help`, `answer`, `observation`, `past_event`, `question`, `routine` | Для каждой ситуации заданы собственные инструкция, критерий и ограниченный набор карточек | Активно |

## Безопасно скрытые задания

| Цели | Почему скрыты | Условие возврата |
|---|---|---|
| `body`, `clothes`, `household`, `places` | Нет полного проверенного набора из 8–12 однозначных изображений | Подготовить и проверить стимульный материал |
| `actions` | Статичная иконка не подтверждает понимание действия | Использовать проверенные фото/анимации действий |
| `qualities`, `opposites` | Один символ без контрастной пары не проверяет признак или противопоставление | Добавить парные стимулы и отдельный сценарий |
| `location` | Текущие карточки не показывают один и тот же предмет в сопоставимых пространственных отношениях | Подготовить контролируемые пары «на / в / под» |
| `commands` | Выбор одной карточки не является выполнением двухшаговой инструкции | Создать последовательность из двух наблюдаемых действий |
| `preference`, `family`, `greeting`, `desire`, `need`, `agent_action`, `spatial_phrase` | Ранее использовали одну и ту же свободную доску при разных обещанных целях | Вернуть только с отдельным сценарием, критерием и набором стимулов |

## Правило публикации

Новое или возвращаемое задание включается только когда одновременно существуют:

1. однозначная инструкция;
2. стимулы, соответствующие заявленной цели;
3. критерий завершения без медицинской интерпретации;
4. сценарий помощи, отказа и технической ошибки;
5. проверка профильным специалистом и представителями целевой аудитории.
