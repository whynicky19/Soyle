# Söyle — итоговая готовность к пилоту

Дата технической приёмки: 7 октября 2026 года.

## Вердикт

**Внутренний контролируемый технический прогон на русском языке — GO.** Он должен проходить только на тестовых данных и под наблюдением команды.

**Внешний пилот с детьми и реальными персональными данными — NO-GO**, пока не закрыты четыре независимых внешних допуска:

1. Юрист/DPO утверждает текст согласия, политику обработки, сроки хранения, процедуру отзыва и удаления данных.
2. Логопед/AAC-специалист подтверждает активные сценарии, стимулы, уровни помощи, формулировки и критерии остановки.
3. Пользователи целевых групп проходят очный accessibility-тест на реальных iOS/Android-устройствах, со screen reader, switch control и масштабом текста 200%.
4. Ответственный за эксплуатацию подтверждает production-конфигурацию, мониторинг, резервное копирование и успешное пробное восстановление PostgreSQL.

KK и EN не входят в текущий внешний пилот. Переключатель интерфейса доступен для технической проверки, но учебный/AAC-контент, свободный текст, редактура носителями и TTS ещё не приняты как единая локализованная версия.

## Матрица ролей

| Роль | Критический сценарий | Способ проверки |
|---|---|---|
| Администратор | Доступ к статистике и аудиту; родитель получает 403 | Автотест API |
| Родитель | Изоляция данных семьи, управление согласиями, программа, домашняя практика | Автотест API + ручной smoke |
| Специалист | Видимость только назначенного ребёнка с действующим разрешением; отчёт поддержки | Автотест API + production build |
| Ученик | Только собственный профиль; согласие доступно для чтения, но не изменения; упрощённая навигация | Автотест API + ручной smoke |

## Матрица ошибок и безопасных исходов

| Ситуация | Ожидаемое поведение | Покрытие |
|---|---|---|
| Нет базового согласия | Результаты и учебная сессия не сохраняются | Автотест |
| Согласие отозвано | Новые операции и доступ специалиста блокируются сразу | Автотест |
| Камера запрещена или выключена | Моторное задание полностью доступно вручную | Ручной smoke |
| Звук/TTS недоступен | Сенсорный результат не оценивается | Автотест + ручной smoke |
| Неизвестный TTS-язык | Запрос отклоняется до генерации аудио | Автотест |
| Отказ или перерыв | Ноль баллов и наград; средние показатели не ухудшаются | Автотест |
| Ручное моторное участие | Засчитывается прохождение и одна звезда, но не «точность» | Автотест |
| Некорректное число правильных ответов | 422; запись не создаётся | Автотест |
| Повторные неверные входы | Временное ограничение после пяти попыток | Автотест |
| Скрытые задания | Не выдаются API и не требуются для завершения модуля | Автотест |

## Выпускной порядок

1. Зафиксировать одобрения четырёх внешних владельцев риска и версию согласия.
2. Сделать резервную копию production-базы и отдельно проверить восстановление в изолированной среде.
3. Развернуть backend с `SOYLE_ENV=production`, уникальным секретом не короче 32 байт, PostgreSQL, точным списком CORS-origin и выключенными демо-данными.
4. Проверить `/health`, миграцию на копии реальной схемы и создание администратора через защищённые переменные окружения.
5. Развернуть frontend с production API URL и повторить smoke всех четырёх ролей.
6. Начать с минимальной когорты, размер которой письменно утверждён ответственным специалистом и DPO; не расширять её до разбора первых наблюдений и инцидентов.

## Откат

- До обновления сохранить проверяемый backup PostgreSQL и идентификатор развёрнутых версий backend/frontend.
- При критической ошибке сначала закрыть новые входы/запись результатов на уровне deployment, затем вернуть обе совместимые версии приложения.
- Не пытаться откатывать схему удалением колонок. Новые поля добавляются совместимо; восстановление данных выполнять из проверенного backup по утверждённому runbook.
- После отката проверить `/health`, вход всех ролей, чтение согласия и отсутствие новых ошибок. Инцидент и затронутые записи зафиксировать в журнале.

## Остаточные ограничения

- Профессиональная и клиническая эффективность не заявляется и не доказана техническими тестами.
- MediaPipe не является измерителем правильности движения или диагностическим инструментом.
- Текущая ручная browser-проверка не заменяет тесты Safari, Firefox и физических мобильных устройств.
- KK/EN интерфейс реализован технически, но редактура носителями, полноценный учебный/AAC-контент и TTS не готовы к внешнему пилоту.
- Для внешнего пилота требуются утверждённые операционные владельцы инцидентов, резервного восстановления и обращений родителей.
